# Lakebase Offers Accelerator

This repository provides a set of free, source-available tools designed to help organizations evaluate the feasibility, cost savings, and performance benefits of migrating to **Databricks Lakehouse / Lakebase**.

Blueprint Technologies created this accelerator to:
- Reduce the time required to assess Lakebase migration readiness  
- Provide transparent, repeatable evaluation workflows  
- Offer practical utilities for data profiling, workload analysis, and cost modeling  
- Help teams validate whether Lakebase is the right strategic fit  

This project is **not open-source**. It is released under the **Blueprint Business Source License (BSL) 1.1**, which allows organizations to use the code internally for evaluation and migration assessment, but **prohibits commercial use, resale, hosting as a service, or white-labeling**.

---

## ✨ What This Accelerator Includes

- Workload and schema assessment utilities  
- Data profiling and Lakebase compatibility checks  
- Cost modeling and TCO comparison helpers  
- Migration readiness scoring  
- Example notebooks and reference architectures
