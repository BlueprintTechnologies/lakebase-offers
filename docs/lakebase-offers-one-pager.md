# Lakebase Offers – One Pager

## Overview
Enable customers to assess and migrate multi‑RDBMS workloads into a unified Databricks Lakehouse. The solution consolidates data, cuts migration time, and lowers total cost of ownership while providing governed, lineage‑rich analytics.

## Core Value
- **Speed**: Up to **40 % faster migrations** via automated schema‑mapping and incremental loads.  
- **Cost**: ~**30 % reduction in TCO** by eliminating duplicate data‑movement licenses and consolidating compute.  
- **Governance**: Single source of truth for lineage, security, and compliance.

## Scoring Formula
```
Raw = ((Pain × Business Impact) / Complexity) × 10
Adjusted = Raw × (1 + Savings% / 100)
```  

- **Score ≥ 25** → **Priority_1** (Proof‑of‑Concept)  
- **10 – 25** → **Evaluate**  
- **< 10** → **Hold**

## Lakebase Pattern Discovery Agent
- **Goal**: Auto‑detect anti‑patterns in query history and surface cost‑attribution insights.  
- **Capabilities**:  
  1. Analyze query logs for Delta Lake anti‑patterns (high‑freq point lookups, small‑write patterns, high‑concurrency reads).  
  2. Profile candidate tables for migration suitability.  
  3. Estimate cost attribution per table/workload.
